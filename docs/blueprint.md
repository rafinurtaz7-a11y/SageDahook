# **App Name**: OfflineSage

## Core Features:

- Document Import: Import local documents (txt, PDF, etc.) to build a private knowledge base.
- Chat Interface: Provide a chat interface to query the local knowledge base using natural language.
- Advanced Summarization: Utilize local AI models to generate summaries of documents and answer questions.
- Content Generation: Generate new content based on the information from the knowledge base. Act as a tool, deciding what information to include from which sources.
- Customizable Styles: Allow users to customize output styles (e.g., formal, informal, technical) for generated content.
- Offline Operation: Ensure the application operates entirely offline for privacy and security.

## Style Guidelines:

- Primary color: Dark blue (#2c3e50) to convey sophistication and trust.
- Background color: Very light gray (#f0f2f5), creating a subtle contrast to focus attention on the main content areas.
- Accent color: Muted teal (#3498db), analogous to blue, used sparingly for interactive elements like buttons.
- Body and headline font: 'Inter', a grotesque-style sans-serif, will create a clean, objective, and readable interface.
- Use simple, clean icons to represent document types and functions within the app.
- Employ a clean, card-based layout for document summaries and search results, ensuring ease of navigation.
- Use subtle animations, such as fades and transitions, to enhance user interaction and provide feedback without being distracting.
